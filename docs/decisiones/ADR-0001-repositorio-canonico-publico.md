# ADR-0001 · Repositorio canónico público

**Fecha:** 2026-10-06  
**Estado:** Aceptada  
**Referencia:** KOS-COM-IA-CAPACIDADES-2026-10-06

## Contexto

La web pública inicial puede desaparecer, cambiar de plataforma o quedar limitada como artefacto visual. Es necesario disponer de una fuente versionada, trazable y exportable.

## Decisión

Usar GitHub como primer repositorio canónico público para la v0.1 de KosmoTIC · Inter-IA · Capacidades.

## Consecuencias

- El contenido queda versionado.
- Las decisiones quedan trazadas por commits.
- Se habilita colaboración futura.
- Se facilita despliegue en GitHub Pages u otros hostings.
- Se reduce el riesgo de dependencia de una única plataforma de publicación.

## Riesgos

- GitHub no debe ser la única copia.
- Se deberá crear copia N+1 en Google Drive, Library/local y posible hosting alternativo.
