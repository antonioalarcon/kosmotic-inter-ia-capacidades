# ADR-0004 · Evidencia como entidad de primer nivel

**Estado:** Aceptada  
**Fecha:** 2026-10-06

## Contexto
KosmoTIC adopta Evidencia → Verdad operativa. Una URL aislada no ofrece identidad, contexto ni trazabilidad suficientes.

## Decisión
Las fuentes y evidencias se modelan como entidades identificables y versionables, susceptibles de relacionarse con capacidades, herramientas, decisiones y experimentos.

## Consecuencias
Mejora la auditabilidad y permite evolucionar hacia niveles de confianza, fechas de consulta, autoría, procedencia y relaciones explícitas.
