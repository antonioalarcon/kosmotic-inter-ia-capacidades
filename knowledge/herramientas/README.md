# Herramientas

Las herramientas se documentan aquí por función, no por moda.

Cada herramienta deberá tener ficha con:

- Función principal.
- Capacidades que habilita.
- Coste.
- Dependencias.
- Riesgos.
- Alternativas.
- Nivel de madurez.
- Criterio de continuidad o descarte.

Estado v0.1: semilla documental.
