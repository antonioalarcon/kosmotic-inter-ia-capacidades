## Criterio rector

La interpretación no pretende describir literalmente el dibujo. Su función es asignar a cada icono un **significado funcional reutilizable** dentro del ecosistema KosmoTIC / Inter-IA.

El catálogo conserva **90 entradas simbólicas**. Algunas comparten icono gráfico, pero representan usos funcionales distintos según el contexto.

## Estados semánticos

**SEMÁNTICO FIJO**: uso estable para conceptos nucleares del sistema.  
**SEMÁNTICO CONTEXTUAL**: uso dependiente del ámbito, conservando familia conceptual.  
**DECORATIVO**: uso libre para ritmo, estética, cercanía o jerarquización sin carga semántica fuerte.

## Dato estructurado asociado

La versión consumible por máquinas queda registrada en:

`data/sistema-grafico.json`

Ese archivo contiene familia, estado semántico y significado funcional de cada entrada.

## Regla de crecimiento

Cuando aparezca un icono nuevo, primero se verificará si aporta una función que no existe. Si no aporta una función nueva, no se incorpora por acumulación.

**La imagen decora. El símbolo ordena. El sistema decide cuándo cada cosa cumple una función.**
