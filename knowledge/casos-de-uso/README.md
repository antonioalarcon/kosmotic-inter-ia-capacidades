# Casos de uso

Los casos de uso conectan capacidades con necesidades reales.

## Criterio

Un caso de uso no se acepta por sonar interesante. Se acepta cuando permite observar, experimentar, validar, medir y aprender.

## Plantilla futura

- Necesidad real.
- Usuario o negocio implicado.
- Capacidad principal.
- Herramientas posibles.
- Datos necesarios.
- Riesgos.
- Métrica de éxito.
- Resultado.
- Decisión: integrar, observar, archivar o vetar.
