# Modelo KosmoTIC

## Secuencia evolutiva

**HERRAMIENTAS → CAPACIDADES → AGENTES → SISTEMAS → INTER-IA → MEMORIA → COORDINACIÓN → GOBERNANZA → SOBERANÍA**

## Lectura operativa

- **Herramientas:** piezas disponibles.
- **Capacidades:** lo que queremos poder hacer.
- **Agentes:** funciones especializadas.
- **Sistemas:** coordinación de componentes.
- **Inter-IA:** colaboración entre inteligencias, fuentes y conectores.
- **Memoria:** continuidad operativa.
- **Coordinación:** asignación de funciones.
- **Gobernanza:** límites, permisos, auditoría y reversibilidad.
- **Soberanía:** decisión humana efectiva.

## Regla

No confundir herramienta con arquitectura.
