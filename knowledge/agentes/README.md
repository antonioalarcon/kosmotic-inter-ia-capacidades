# Agentes

Un agente IA es una función especializada con reglas, límites, permisos y supervisión.

## Plantilla futura de agente

- Nombre.
- Propósito.
- Entradas.
- Salidas.
- Herramientas permitidas.
- Memoria disponible.
- Límites.
- Escalado humano.
- Métricas.
- Riesgos.
- Criterios de retirada.

Regla v0.1: ningún agente debe recibir más autonomía de la necesaria para cumplir su función.
