# Protocolos

Protocolos operativos que convierten principios en secuencias ejecutables.

Cada protocolo deberá declarar como mínimo: propósito, alcance, entradas, secuencia, criterios de decisión, salida, supervisión humana, evidencias y versión.

Regla: un protocolo no adquiere autoridad por estar documentado; debe estar validado y su estado debe ser explícito.
