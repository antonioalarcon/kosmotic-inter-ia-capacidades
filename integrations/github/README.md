# GitHub

## Función inicial

GitHub queda establecido como primer repositorio canónico público de la v0.1.

## Usos

- Versionado.
- Trazabilidad.
- Colaboración futura.
- Despliegue web posible.
- Auditoría por commits.
- Base para automatizaciones.

## Regla

Toda modificación estructural relevante debe quedar documentada mediante commit y, cuando corresponda, mediante ADR.
