# Integraciones

Esta capa define cómo se conectará KosmoTIC · Inter-IA con sistemas externos autorizados.

## Principio

Los conectores no son decoración. Son capacidades operativas.

Cada integración debe definir:

- Sistema conectado.
- Permisos mínimos necesarios.
- Datos que puede leer.
- Datos que puede escribir.
- Riesgos.
- Auditoría.
- Reversibilidad.
- Alternativas N+1.
