# ChatGPT

## Función inicial

- Escritura y lectura asistida del repositorio GitHub.
- Generación de documentación.
- Estructuración de conocimiento.
- Preparación de copias N+1.
- Coordinación inicial de tareas.

## Criterio de uso

ChatGPT actúa como interfaz operativa, no como única fuente de verdad.

## Riesgo a vigilar

No confundir conversación con persistencia. Lo canónico debe quedar versionado en repositorio, documentos o datos estructurados.
