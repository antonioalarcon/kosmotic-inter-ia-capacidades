# API

Capa futura para exponer o consumir datos estructurados desde servicios externos.

## Posibles usos

- Consumir `/data` desde una interfaz web.
- Alimentar agentes.
- Integrar CRM, formularios, automatizaciones o sistemas internos.
- Publicar capacidades como catálogo consultable.

## Regla

No abrir API sin definir permisos, límites, auditoría y reversibilidad.
