# Registro Federado de Nodos IA · fichas 001 y 002

Fecha: 2026-10-19. Autoridad soberana: Antonio Alarcón Izquierdo ✔️.

Este directorio contiene **fichas internas de gobernanza**, no Agent Cards A2A publicadas ni endpoints operativos.

- Ficha 001: `NODO-GEMINI.json` · Nodo B.
- Ficha 002: `NODO-CHATGPT.json` · Nodo A.

Los IDs se mantienen consistentes con `03_REGISTRO_NODOS_IA` del cuadro de mando de Google Sheets. `NODO-B-GEMINI` es un alias propuesto, **no** un ID alternativo adoptado.

`mcp_verificado=false` y `a2a_verificado=false` indican ausencia de pruebas de interoperabilidad reproducibles; no son un juicio sobre las capacidades generales del producto.

`agent_card_publicada=false` y `a2a_endpoint=null` evitan afirmar que una ruta GitHub es un endpoint A2A funcional. Una Agent Card futura requerirá perfil compatible con la versión A2A elegida, alojamiento autorizado, autenticación, descubrimiento y prueba de conexión.

Estas fichas no incluyen secretos, tokens ni datos personales de terceros. La publicación en un repositorio público no concede permisos ni sustituye la aprobación de Antonio.
