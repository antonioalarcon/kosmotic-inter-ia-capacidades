# Archivo

La carpeta `archive/` conserva material histórico, versiones congeladas y elementos retirados.

## Regla

Archivar no significa borrar. Significa sacar del flujo activo sin perder trazabilidad.

## Usos

- Versiones previas.
- Experimentos cerrados.
- Material sustituido.
- Decisiones obsoletas.
- Copias de seguridad documentales.
