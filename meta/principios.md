# Principios

1. Persona → Soberanía.
2. Infraestructura → Coordinación.
3. IAs → Inteligencia distribuida.
4. Conectores → Capacidades.
5. N+1 → Resiliencia.
6. Evidencia → Verdad operativa.
7. Capacidad antes que proveedor.
8. Datos y conocimiento antes que vistas.
9. Reversibilidad antes que dependencia.
10. Automatizar calidad sin automatizar criterio.
