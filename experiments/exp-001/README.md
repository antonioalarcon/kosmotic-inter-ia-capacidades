# EXP-001 · Sobrecarga informativa

Estado: **semilla**

## Hipótesis

Una parte relevante de la fricción diaria no procede de falta de inteligencia, sino de exceso de entradas sin filtrado, priorización ni cierre operativo.

## Objetivo

Diseñar una forma mínima de capturar, clasificar y convertir inputs en acciones, observaciones, archivo o descarte.

## Métricas candidatas

- Número de inputs diarios.
- Tiempo de fricción.
- Nivel de saturación percibida.
- Porcentaje de conversión input → acción útil.

## Relación con KosmoTIC

Este experimento conecta memoria operativa, soberanía atencional, automatización, auditoría y coordinación Inter-IA.
