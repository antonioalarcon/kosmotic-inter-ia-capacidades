# Experimentos

Los experimentos convierten necesidades reales en aprendizaje medible antes de integrar tecnología como dependencia.

## Secuencia

**OBSERVAR → EXPERIMENTAR → VALIDAR → ASIGNAR FUNCIÓN → INTEGRAR → REEVALUAR**

## Estados posibles

- Candidato.
- En observación.
- En prueba.
- Validado.
- Integrado.
- Archivado.
- Vetado.

## Regla

No se integra una tecnología porque exista. Se integra cuando demuestra contribución neta.
